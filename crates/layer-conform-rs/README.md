# layer-conform-rs

Rust adapter for [layer-conform](https://github.com/9wick/layer-conform), built on [syn](https://github.com/dtolnay/syn).

This crate is part of the layer-conform CLI; users typically install only the CLI:

```sh
cargo install --locked layer-conform
```

See the [main README](https://github.com/9wick/layer-conform) for usage.
